
# Sound Merge

The complete music industry platform for artists. AI-powered sync licensing, distribution, revenue recovery, and real-time analytics.

## 🚀 New Features (v2.5)

### 1. Multi-Engine AI Architecture
Sound Merge now supports a diverse array of neural processing nodes, allowing artists to choose the right AI engine for every specific project:
- **Udio & Suno**: Full-track synthesis with radio-ready song structures.
- **Mureka**: Specialized high-fidelity instrumental and cinematic engine.
- **MusicGPT**: Rapid text-to-audio prototyping for fast iteration.
- **AI Music**: Experimental genre-blending and aggressive texture generation.

### 2. Real-Time Data Layer (RapidAPI)
We have integrated **RapidAPI** to replace static mock data with live industry metrics.
- **A&R Dashboard (Billboard)**: Fetches the live **Billboard Hot 100** chart.
- **Analytics (Spotify)**: Pulls real-time **Spotify Artist Stats** and Track Stream counts.

### 3. Merge Assets (Ledger)
- Assets are persisted to local storage and the blockchain for instant rights verification.
- A dedicated "Asset Vault" allows for quick management of Digital Rights Certificates.

### 4. VoiceShield™
- Biometric voice fingerprinting secured on the **Solana** blockchain.
- Build your **Merge Reputation** to earn future $MERGE utility tokens.

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide React
- **AI**: Google Gemini (GenAI SDK), NeuralForge Multi-Engine (Udio, Suno, Mureka, etc.)
- **Data**: Firebase (Firestore/Auth), RapidAPI (Billboard/Spotify)
